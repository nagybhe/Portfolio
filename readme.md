## 📋 Sobre o Projeto
Portfólio profissional desenvolvido em React com design moderno e componentes modulares. Apresenta projetos, habilidades e experiência de forma elegante e responsiva.

## 🏗️ Estrutura do Projeto
```
portfolio-react/
├── public/ # Arquivos públicos
├── src/
│ ├── components/ # Componentes React
│ │ ├── About/ # Seção sobre
│ │ ├── ContactModal/ # Modal de contato
│ │ ├── Header/ # Cabeçalho
│ │ ├── Hero/ # Seção hero
│ │ ├── Portfolio/ # Projetos
│ │ ├── ProjectModal/ # Modal de projetos
│ │ ├── Resume/ # Currículo
│ │ └── Skills/ # Habilidades
│ ├── App.js # Componente principal
│ ├── App.css # Estilos globais
│ └── index.js # Ponto de entrada
└── package.json # Dependências
```

## 📦 Instalação e Uso

```bash

cd Portfolio

# Instale as dependências
npm install

# Execute em desenvolvimento
npm start

# Build para produção
npm run build
